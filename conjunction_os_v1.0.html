III · NAND ring adder 100% verified

A single primitive (NAND) in a ring. Each breath: sum = a XOR b (no carry), remainder = carry = a AND b. The remainder is routed back around the ring — never discarded — until it settles to zero (phase lock). Average breaths-to-lock ≈ log₂(width); worst case = width.

IV · Reversible adder (Toffoli+CNOT) reversible · 0 erased

The Cuccaro ripple-carry adder. Adds with zero bit-erasure (Landauer cost 0). The inverse is the same gates run backward — reversal without recalculation. The carry ancilla returns to 0 (phase lock); inputs are recoverable.
